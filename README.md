 Fake Project Detector

 Project Description
Fake Project Detector is a web application developed using Python Flask. It helps users identify whether a project is genuine or potentially fake based on the provided project details.

Features
- User-friendly interface
- Project detail analysis
- Fake project detection
- Database integration
- Fast and simple workflow

Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

Project Structure
```
Fake_Project_Detector/
│── app.py
│── database/
│── static/
│── templates/
```

 Installation

1. Clone the repository
```
git clone https://github.com/sebastina183/Fake_Project_Detector.git
```

2. Go to the project folder
```
cd Fake_Project_Detector
```

3. Install dependencies
```
pip install -r requirements.txt
```

4. Run the application
```
python app.py
```

5. Open your browser
```
http://127.0.0.1:5000
```
